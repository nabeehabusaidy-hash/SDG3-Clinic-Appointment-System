Testing Objective:
The objective of testing the Clinic appointment system prototype is to evaluate the usability and functionality of the system . It focuses on making sure the users can successfully and easily perform the key tasks such as viewing available appointments slots , booking appointments , managing existing appointments. Evaluating this will help identify any potential issues the system could face  and makes sure the prototype is meeting the basic user requirements and system requirements.
Testing Method :
Usability Testing with several participants representing different user roles . Firstly , The users were asked to perform common tasks such as viewing available appointments slots , booking appointments , managing existing appointments. Secondly, the tester will observe whether the tasks can be completed successfully and then the outcomes and feedbacks will be recorded. Finally, participants provided feedback and it was analysed to identify potential improvements for the final prototype .

User feedback 
To be able to perfectly evaluate the usability of the clinic appointment system prototype , the following users were asked to interact with the system. They performed basic tasks ( viewing appointments slots, booking appointments , managing existing appointments). Their feedback is then collected and it helped with understanding how intuitive the interface is and it also helped with identifying areas for improvement.
Participant 1 – Student 
Feedback from participant:  The system was generally easy to use but the navigation between pages was not immediately clear. The participant suggested making the system flow more structured to guide users.
Observation from tester: the participant was able to complete the booking task but required a few moments to locate correct page 

Participant 2 – Student 
Feedback from participant: The participant noted that the system interface looked visually simple but suggested improving the overall layout to be more user friendly and the features easier to identify 
Observation from tester: The participant completed the booking and cancellation task with no assistance 

Participant 3 – Clinic staff
Feedback from participant: The staff participant indicated that some features were not necessary for the initial system prototype and that it looked overcrowded. Also suggested to focusing mainly on appointment management tasks 
Observation from tester: The participant completed a status update quickly but took some time to understood the dashboard 

Participant 4 – Admin
Feedback from participant: The admin suggested that different system roles should have clearer login options to ensure users access the correct dashboard 
Observation from tester: The participant successfully accessed the admin section but recommended improving role separation in the login page 

System improvements 
Based on the feedback collected during usability testing , some improvements were implemented in the final prototype.
	In the login system 3 buttons were added allowing users to log in as a student, staff or admin. This improvement guarantees that users are always directed to the correct system dashboard.
	The system navigation was improved to provide a clearer workflow between pages such as booking appointments, viewing appointments and managing existing bookings. This will help students understand and move through the system easily 
	The visual layout was refined to be more user friendly and organized. The improved design helps users quickly identify important buttons and system functions hence leading to a better user experience 
	Finally during the evaluation of the early prototype it was identified that several admin and staff features increased the system complexity and that most features were not important for the initial version of the system. Based on usability feedback and the project time constraint the final prototype focused on delivering minimum viable product ( MVP).
The MVP prioritizes only core functionalities for the system to operate. This approach ensured the final prototype is clear, functional and user friendly and also demonstrating the key capabilities of the clinic appointment system.
