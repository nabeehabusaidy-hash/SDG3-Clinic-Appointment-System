# Sprint 1 Planning

## Sprint Goal
To design the main structure of the clinic appointment system by defining requirments such as user stories and product vision and also creating design that supports that like class and use case diagrams. In addition of creating the early prototype by providing UI sketches.


## Selected Tasks 
- Define the project requirments
- Create product vision
- Create user stories
- Create use case diagram
- Create class disgram
- Design UI wireframes 

## Sprint duration
Week 2 

## Expected Outcome
By the end of sprint 1 the team will have completed and prepared all the system requirments making the goal for the final prototype very clear. In addition UML diagrams and the UI sketches and wireframes for the early prototype.
