# User Stories

## Students 
- As a student I want to log in to the univeristy clinic appointment system so that I can easily manage my healthcare needs online without physically visiting the actual clinic.
- As a student I want to book a clinic appointment so that I can manage my schedule efficently and not wait in long lines at the clinic
- As a student I want to view the available appointment time slots so that I can choose the best option for me depending on my schedule
- As a student I want to cancel or reschedule my appointment so that I can manage unexpected changes in my schedule 


## Clinic Staff
- As a clinic staff member I want to log in to the clinic appointment system so that I can securely access and manage appointments without physically dealing with alot of students
- As a clinic staff member I want to view the daily appointments so that I can manage patient flow efficently depending on the day
- As a clinic staff member I want to update each appointment status so that students can always remain up to date 


## Admin
-As an admin I want to log in to the clinic appointment system so that I can securely access the system and manage admin functions
- As an admin I want to manage user accounts by editing information or deleting users or changing roles so that the system stays organized and the right people have the appropriate access
