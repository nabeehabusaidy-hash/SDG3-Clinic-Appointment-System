# User Stories – Clinic Appointment System

## Student
- As a student, I want to book a clinic appointment online so that I save time and avoid queues.
- As a student, I want to view available time slots so that I can choose a convenient appointment.
- As a student, I want to cancel or reschedule my appointment so that I can manage unexpected changes.

## Clinic Staff
- As a clinic staff member, I want to view daily appointments so that I can manage patient flow efficiently.
- As a clinic staff member, I want to update appointment status so that records remain accurate.

## Admin
- As an admin, I want to manage users so that only authorized users access the system.
