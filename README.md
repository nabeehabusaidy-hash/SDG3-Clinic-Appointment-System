# SDG 3 Clinic Appointment System 
SDG 3 Clinic Appointment System: This project is a software prototype designed to improve access to university healthcare. It enables students to book clinic appointments online and allows staff to manage schedules and records digitally. One of the main benefits of this system is that it reduces anxiety for students and staff from the overwhelming feeling of managing schedules and it significantly reduces waiting time. In conclusion, this directly supports SDG 3: Good Health and Well-Being.

# SDG3 - Clinic Appointment System

## Sustainable Development Goal
This project supports SDG3 by providing better access to healthcare services for university students. The appointment system being digital makes the overall data management and scheduling management way more organized. This leads to an overall improved healthcare experience on campus.

## Project Description 
The Clinic Appointment System is a software prototype developed for university students, clinic staff and administrators. Many university clinics still rely on manual appointment booking systems which can cause overcrowding and inefficient schedule management. That's why this system provides a digital solution where students can view and book appointments online. At the same time clinic staff can manage appointments schedules and update their status easily through the system and admins can organize and keep track of the system.


## SDLC Overview 
The development of this project followed the Software development life cycle using agile and scrum practices. 
Planning And requirements  phase: We identified user needs and main system requirements 
Design phase: We created UML diagrams and UI sketches and wireframes to show how the system will work 
The prototype was then developed in iterations through the use of sprints. 
Finally the system was tested using usability testing and feedback collection to create a final improved and user focused prototype
